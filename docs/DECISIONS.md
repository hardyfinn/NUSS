# Decisions made while building

Choices the spec left open, or where the build differs from it. Values marked [est] in the spec are in `src/dsp/Constants.hpp`.

## Whole plugin
- **Test harness:** the spec named doctest; the build reuses Silverbox's small dependency-free harness (`tests/check.hpp`), which does the same job.
- **Controls:** Rack's own component library (RoundBlackKnob, Trimpot, PJ301MPort, VCVLightBezel with RGB lights) instead of custom SVG components. Panels are generated by `scripts/make_panels.py`, which also writes the widget placement code so drawing and controls can't drift apart.
- **CPU test:** the host test fails only above 2% of a core (EFG, ETS) and 0.5% (EGX), because shared CI runners are slow and noisy. On this build machine the engines measured about 0.4% (EFG with all eight channels cycling), 0.5% (ETS) and 0.06% (EGX). To get there: EFG refreshes its per-channel coefficients every 8 samples (and at once on activation), skips the oscillator on idle channels, and uses a fast power approximation (error under 0.001) for the curve law; ETS refreshes its speed multipliers every 16 samples or when Spread changes.
- **Rise/Fall law:** the spec's formula (0.5 ms × 2^(25.25p)) contradicted its own stated range (p = 1 would be 5.5 hours). Used 0.5 ms × 2^(16p): 0.5 ms to 33 s on the knob, with CV reaching about 20 minutes (MATHS's quoted maximum). Default Rise 0.25 (8 ms), Fall 0.6 (390 ms).

## EFG
- Rate is disseminated but not spread (the PoliMATHS manual contradicts itself; the spec chose the Spread section's list).
- Index receive: the incoming index also re-fires on RESET.
- Binary: the channel SPAN selects fires every gate; channels to its right follow bits of the counter, channels to its left follow a mirrored counter, so neighbours on both sides flip most often.
- Re-activating a running channel restarts its Rise from the current level (MATHS-style), and resets the oscillation phase.
- The POLY output carries the eight unmixed channels even when Submix is on.

## ETS
- The write-head resync under Tempo moves every read head by the same amount, so the heads keep their relationship.
- STEP RANDOM reads and holds one value per cycle; RAMPLETS jumps to a random spot each cycle and plays forward from it.
- HOLD IN: held while its gate is high (spec's reading).
- The Range button's light is dimmed while IN is patched, because the range only affects the internal LFO.

## EGX
- **10 HP, not the spec's 8 HP**, to fit 14 labelled jacks with room for fingers.
- Index mode is detected at the reference knob positions (SPAN ≤ −0.98, ATTEN ≥ 0.98, SPACE ≥ 0.98), rather than by band maths.
- Under CLOCK, a fresh index (even the same channel again) fires PULSE at the next clock edge.
- INDEX OUT is an addition; the GTE has none.
